# Game.Flame

Модуль ресурса пламени (жизни и света свечи):

- `IFlameService` / `FlameService` — пассивное угасание огня со временем, регенерация в безопасных зонах зажжённых фонарей, расход на рывки, урон от ветра/врагов, событие `OnFlameExtinguished` и управляемая жертва пламени в финале (`SacrificeDrainAsync`).
- `CandleLightView` — связывает уровень пламени с радиусом/интенсивностью URP 2D `Light2D` и пульсирующим примитивным огоньком.

См. [ROADMAP.md](ROADMAP.md).
