# Game.UI

UI-компоненты и экранные оверлеи на UGUI + TextMeshPro + PrimeTween:

- `ScreenFader` — плавное затемнение при загрузке сцен и респавне.
- `GameplayHudView` — шкала пламени, название локации с баннером смены зоны, список собранных предметов, контекстная подсказка `[E]` и тосты событий.
- `StoryOverlayView` — чёрный экран Пролога со вступительным текстом и экран Финала с кнопкой «Сыграть снова».

См. [ROADMAP.md](ROADMAP.md).
