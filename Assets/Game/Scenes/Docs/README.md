# Scenes

Сцены, зарегистрированные в `EditorBuildSettings`:

0. `Assets/Game/Scenes/Boot.unity` — стартовая сцена с `BootLifetimeScope`, инициализацией `ILocalizationService`, `ISettingsService`, `IInputService`, `ScreenFader` и асинхронным переходом в `Gameplay`.
1. `Assets/Game/Scenes/Gameplay.unity` — полный непрерывный top-down маршрут из 4 актов: Пролог (Заброшенная комната) -> Локация 1 (Забытый лес, мост из досок, спичка и фонарь) -> Локация 2 (Заброшенная шахта, доски над обрывом, вагонетка, ветры с каменными укрытиями, Дух ветра, мастерская с рычагом/дверью/взрывчаткой, обвал) -> Локация 3 (Маяк: ключ возле тележки, 1-й этаж с ползунами и рычагом, винтовая лестница с ветрами, вершина и жертва огня великой лампе).

См. [ROADMAP.md](ROADMAP.md).
