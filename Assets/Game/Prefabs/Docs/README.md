# Prefabs

Все игровые объекты сцены `Gameplay.unity` собраны как модульные префабы из цветных примитивов:

- **Персонаж:** `Char_CandlePlayer` (`Rigidbody2D`, `CircleCollider2D`, `CandleController`, `CandleLightView`, `Light2D`)
- **Чекпоинты и маяк:** `Prop_LanternCheckpoint`, `Prop_LighthouseLamp`
- **Механизмы и преграды:** `Prop_Door`, `Prop_Lever`, `Prop_BridgeSite`, `Prop_Minecart`, `Prop_Rockfall`
- **Предметы:** `Pickup_Match`, `Pickup_WoodPlank`, `Pickup_Explosive`, `Pickup_LighthouseKey`, `Pickup_WaxEmber`
- **Враги и опасности:** `Enemy_ForestShadow`, `Enemy_Crawler`, `Enemy_BlowerSpirit`, `Hazard_WindGustZone`, `Hazard_PitZone`
- **Окружение и UI:** `Env_FloorPanel`, `Env_WallBlock`, `Env_WindCover`, `Env_TreeCluster`, `Env_CrateProp`, `Zone_Trigger`, `UI_GameplayCanvas`

См. [ROADMAP.md](ROADMAP.md).
