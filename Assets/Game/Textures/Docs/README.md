# Textures

Геометрические примитивы для визуализации всех объектов без сторонних ассетов:

- `Tex_PrimSquare.png` — квадрат 32x32 (`PPU = 32`, `Point`), используется для стен, дверей, досок, моста, укрытий, вагонетки и панелей UI.
- `Tex_PrimCircle.png` — сглаженный круг 64x64 (`PPU = 64`, `Bilinear`), используется для свечи, огня, углей, духа ветра, фонарей, крон деревьев и вспышек.

См. [ROADMAP.md](ROADMAP.md).
