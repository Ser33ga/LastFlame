# Assets/Game — Last Flame

Корневая папка проекта **«Последний огонёк» (Last Flame)** — top-down 2D-игры на цветных геометрических примитивах с динамическим светом URP 2D (`Light2D`), без сторонних спрайтов и аудио.

## Основные разделы
- [Scenes](../Scenes/Docs/README.md) — сцены `Boot.unity` и `Gameplay.unity`
- [Prefabs](../Prefabs/Docs/README.md) — 25 префабов игрока, врагов, препятствий, окружения и UI
- [Textures](../Textures/Docs/README.md) — процедурные примитивные спрайты (`Tex_PrimSquare`, `Tex_PrimCircle`)
- [UI](../UI/Docs/README.md) — шрифт `Font_MainSDF` с поддержкой кириллицы
- [Scripts](../Scripts/Docs/README.md) — модульные C#-сборки (`.asmdef`) с VContainer DI, UniTask и PrimeTween

См. [ROADMAP.md](ROADMAP.md).
